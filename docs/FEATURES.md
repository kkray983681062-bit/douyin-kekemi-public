# 功能与权限

本文描述源码已有能力；线上是否启用取决于部署配置、账号角色和抖音接口可用性。

## 房间与实时数据

支持抖音号、用户主页链接、直播间链接。抖音号支持点号和连字符，解析失败会复位页面状态并说明原因。常驻房间来自 `DEFAULT_WATCH_IDS`，同时监听上限由 `MAX_ROOMS` 控制（默认 10），下播后等待下次开播。

临时房间仅超级管理员可访问；移除临时房间会停止监听。房间栏支持横向滚动和鼠标拖动。

神秘人、在线观众、公屏与榜单按房间隔离。在线页展示可获取的观众和麦上主持；身份关联依据可用 UID 等标识，不用昵称相似度猜测身份。

公屏保留聊天和礼物，不展示进场刷屏；礼物可展示收礼主持。向上滚动冻结视图并累计新消息提示。普通聊天约 3 秒增量查询，神秘人等相关事件继续通过 SSE 推送。

## 礼物与榜单

- 日榜区分游客送出与主持收到，采用北京时间当日口径。
- 主持周榜、游客周榜提供时段与明细查询，已归档周期可按现有接口读取。
- 已关联到同一身份的不同标识可合并，未建立关联的身份保持独立。
- 礼物库支持搜索、价格来源、未知价格、礼物名称 / 皮肤定价及修改历史。
- 归属修正支持按送礼人或收礼主持搜索、修正归属和备注，保留原始事件。
- 本轮上麦票数与当日累计票数分别展示。

## 主持文字静默提醒

管理员按厅订阅，通过铃铛面板管理订阅及提醒，各自拥有订阅和已读状态。默认连续 15 分钟没有捕获到主持的文字发言时提醒。

次数按北京时间自然 2 小时档统计。同档达到 3 次时，在数据流仍有效等条件成立的情况下形成聊天快照，记录相关时段和消息间隔。恢复文字发言、下麦或关闭房间后按状态收尾。快照不参与普通聊天的 7 天清理。

此功能不是语音识别或录音，不能用于认定主持没有说话；断流和消息缺失会影响判断。

## 账号管理

邀请码注册后进入待审核状态，通过后才能进入业务页面。支持密码找回、被驳回后重新提交申请、退出登录和服务端会话检查。

| 操作 | 成员 | 管理员 | 超级管理员 |
| --- | --- | --- | --- |
| 查看常驻房间、在线、公屏、日榜 | 是 | 是 | 是 |
| 周榜、礼物库、归属修正、文字静默 | 否 | 是 | 是 |
| 账号审核、暂停 / 恢复（受角色约束） | 否 | 是 | 是 |
| 解析、启动、停止监听 | 否 | 否 | 是 |
| 临时房间 | 否 | 否 | 是 |
| 调整角色、强制下线、账号删除 | 否 | 否 | 是 |
| 账号私人备注 | 否 | 否 | 是 |

账号删除需要确认用户名和原因，服务端限制自删、超级管理员目标等情况。约束以 `kekemi_auth/service.py` 和数据库函数为准。

## 性能与运维

SSE 使用独立订阅队列；JSON 和流式消息分别压缩。只读接口使用短时缓存、ETag / 304 及增量查询。后台标签页暂停房间、公屏、在线和榜单的常规轮询，返回前台补刷新。

`/healthz` 检查存活；`/version` 提供版本信息。`scripts/verify_deploy.py` 通过显式 URL 或 `DEPLOY_BASE_URL` 对照代码指纹。健康检查成功不等于成功采集了直播数据。
