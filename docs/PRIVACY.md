# 隐私与数据说明

## 公开分发范围

程序、页面资源、虚构测试样本和通用文档可进入公开分发。真实 Cookie、令牌、密钥、邀请码、生产数据、真实用户标识、私人账号列表、个人隧道地址和内部部署记录应保留在私有环境。

测试中的演示人物、房间和标识不是实际账号资料。个人开发规则、内部实施记录和针对特定账号的临时探针不属于公开产品文档。

## 运行时数据

- SQLite 保存互动、礼物统计、身份关联和部分管理记录。
- 当前在线接口不构成完整历史观众名单。
- 聊天、礼物明细、普通观众资料及普通告警按默认保留期清理，当前默认 7 天。
- 身份档案、静默聊天快照、部分周榜归档以及价格 / 归属修改历史不应被理解为全部在 7 天后删除。部署者应管理这些记录和备份。
- Supabase 承担认证、角色及相关服务端状态；服务端密钥不交给浏览器。
- 超级管理员私人备注仅对相应权限开放。

匿名身份只能依据可用标识关联，无法确认时保留匿名。普通用户改昵称不应成为展示其曾用名的理由。

## 诊断与问题报告

Cookie 检查脚本只打印字段是否存在和长度。登录辅助代码不输出完整 Cookie 或可能含凭证的响应头。版本核对需要部署者显式提供服务地址。

提交 Issue、日志或截图前，移除 Cookie、令牌、邮箱、UID、个人昵称、聊天文本和生产域名，并用虚构样本复现问题。

`.gitignore` 和 `.dockerignore` 减少误上传，但不能消除已经进入 Git 历史、PR 或备份的内容。公开既有私有仓库前应另行检查历史记录。
